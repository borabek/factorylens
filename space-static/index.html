FactoryLens

Anomaly detection with an RGB camera and a 3D sensor together, and a fusion that notices, without labels, when one sensor starts failing and stops trusting it. Everything below was computed in advance with the project's own code; nothing runs in your browser except this page.

Before each part, the reliability window holds 15 normal parts in the same sensor state, as on a line that has been running. Corruptions are applied at severity 3 of 5. Anomaly maps are in standard deviations of the validation parts; colour starts above 0.

The product's test parts in random order; one sensor is corrupted (severity 3) from the middle of the run on. Both fusions use the same alarm threshold, set on normal validation parts for a 10% false alarm rate.

Code, method and results: github.com/borabek/factorylens (commit ).
